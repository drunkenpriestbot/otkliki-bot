# Webhook для бота (Cloudflare Workers)

Два сценария в одном воркере:
1. Reply на сообщение бота со своим отредактированным текстом — воркер находит
   ссылку на заказ в исходном сообщении и прикрепляет такую же кнопку
   «Перейти к заказу» к отредактированному сообщению.
2. Нажатие кнопки «Сгенерировать отклик» под превью-карточкой — воркер сразу
   убирает кнопку, шлёт в чат сообщение «Отклик отправлен на генерацию» и
   дёргает GitHub Actions (workflow_dispatch на monitor.yml с
   action=generate), которая уже сама генерирует черновик (Claude) и шлёт
   его в Telegram.

Бесплатно, без карты, работает всегда (не нужно держать комп включённым).

## Установка (один раз)

1. Установи Wrangler (CLI Cloudflare), если ещё нет:
   ```
   npm install -g wrangler
   ```

2. Залогинься (откроется браузер, заведи бесплатный аккаунт Cloudflare, если
   его ещё нет — без карты):
   ```
   wrangler login
   ```

3. Из этой папки (`cloudflare-worker/`) задеплой воркер:
   ```
   wrangler deploy
   ```
   В выводе появится адрес вида `https://otkliki-monitor-webhook.<твой-сабдомен>.workers.dev`
   — он понадобится на шаге 6.

4. Добавь токен Telegram-бота как секрет воркера (значение нигде не светится
   в команде, Wrangler спросит его в интерактивном вводе):
   ```
   wrangler secret put TELEGRAM_BOT_TOKEN
   ```

5. Добавь GitHub PAT (fine-grained, права Actions: Read and write только на
   репозиторий otkliki-bot — тот же, что используется для cron-job.org, или
   отдельный) как секрет воркера:
   ```
   wrangler secret put GITHUB_PAT
   ```
   `GITHUB_REPO` (owner/repo) уже задан как обычная переменная в `wrangler.toml`
   — менять не нужно, если репозиторий не переименовывался.

6. Зарегистрируй вебхук у Telegram (выполни сам в своём терминале — подставь
   свой токен бота и адрес воркера из шага 3). Параметр `allowed_updates`
   обязателен — без него Telegram по умолчанию не шлёт нажатия кнопок
   (callback_query):
   ```
   curl -F "url=https://otkliki-monitor-webhook.<твой-сабдомен>.workers.dev" \
     -F 'allowed_updates=["message","callback_query"]' \
     "https://api.telegram.org/bot<ТВОЙ_ТОКЕН_БОТА>/setWebhook"
   ```
   Ответ должен быть `{"ok":true,"result":true,...}`.

## Проверка

- Ответь (Reply) на любое уведомление бота произвольным текстом — должно
  прийти сообщение «✏️ Отредактированный вариант» с кнопкой «🔗 Перейти к
  заказу», ведущей на тот же заказ, что был в исходном уведомлении.
- Нажми «✍️ Сгенерировать отклик» под превью-карточкой — кнопки должны сразу
  пропасть, прийти всплывающий тост «Генерирую черновик…», а через ~30-60
  секунд — отдельное сообщение с полным черновиком (проверить можно через
  `gh run list -R drunkenpriestbot/otkliki-bot --workflow=monitor.yml`, должен
  появиться новый запуск с event `workflow_dispatch`).
